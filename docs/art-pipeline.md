# 성인 모험 판타지 · A 방향

2026-10-07 선택 방향은 `art/references/mature-rpg-2026-10-07/a-stylized-adventure.png`입니다.
성인 체형과 실용적인 여행 장비, 천·가죽·철의 구분, 넓은 초원과 원정대 생활감을 기준으로 합니다.
숲과 던전은 같은 모델·재질을 사용하면서 차가운 안개와 따뜻한 등불로 분위기를 전환합니다.
AI 시안은 목표 참고 이미지이며 실제 게임 화면이나 완성된 3D 모델이 아닙니다. 이전 C 방향은 사용하지 않습니다.

## 1차 적용 범위

구·캡슐 캐릭터를 약 1.95m 성인 비율의 원본 GLB로 교체했습니다.
19개 관절과 스킨 가중치, 코트·부츠·벨트·배낭·도끼를 사용합니다.
플레이어·목수·운반원은 같은 뼈대를 공유하고 코트 색·앞치마·배낭·도구로 구분합니다.
애니메이션은 Idle, Walk, Run, Jump, Slash, Slam, Dodge, WorkHammer, CarryIdle, CarryWalk, Cast의 11개입니다.
손의 grip_r/grip_l과 몸통의 부착점을 통해 도구와 짐을 연결합니다. 공격 시간은 게임의 진행률과 동기화합니다.
짐을 들면 무기와 마법 지팡이를 숨기고, 짐을 놓으면 장비 상태를 복원합니다.

원정대 300명은 개별 스켈레톤 대신 성인 비율의 MultiMesh 몸·머리·머리카락·다리를 사용합니다.
천막·짐상자·판자 마차·바퀴살, 가지가 갈라지는 나무·각진 수관·바위와 산, 흙과 천의 표면 셰이더를 적용했습니다.
출발 야영지와 전진 기지가 같은 환경 자산을 사용하며 기존 충돌 크기와 주요 동선은 유지합니다.

## 자산 위치

- art/source/characters/build_adventurer.py: 직접 작성한 단면 메시·스킨·키프레임의 수정 가능한 원본
- assets/models/characters/: 게임용 GLB
- assets/models/props/: 텐트·수레·도구·건물
- assets/textures/: 텍스처
- assets/audio/: 음악·효과음

## 캐릭터 2차 적용 · 2026-10-07

옷·장갑·부츠·얼굴의 곡면 노멀을 다듬고 코트 자락과 앞치마를 곡면 패널로 바꿨습니다.
천·가죽은 환경과 같은 표면 셰이더를 사용합니다. 주인공·목수·운반원에 얼굴과 머리 변형을 따로 두고,
금속 어깨 갑옷은 주인공만 사용합니다. 19관절·11클립과 외부 animate API는 유지합니다.

`character_hands.gd`는 가로베기·내려찍기의 무기 경로와 두 손 접촉을 보정합니다.
오른손 grip_r에 무기가 붙고, 왼손은 도끼 로컬 (0, -0.22, 0)을 잡습니다. 준비·마무리에 접촉을 섞으며
게임의 적중 시점(가로베기 0.16/0.52, 내려찍기 0.36/0.72)에 경로의 타격 지점을 맞춥니다.
운반할 때는 가슴에 붙은 짐 양옆을 두 손으로 받칩니다. 팔 길이는 늘리지 않습니다.

`character_feet.gd`는 실제 이동 거리로 보폭을 진행시키고 디딘 발의 월드 위치를 유지합니다.
환경 충돌 레이어 1을 검사해 발바닥을 경사에 맞춥니다. 골반과 무릎은 시각적으로만 보정하며 충돌체는 건드리지 않습니다.
시작·정지에서 자세를 섞고 점프·회피·큰 위치 변경에는 고정을 해제합니다. 바닥을 찾지 못하면 원본 클립으로 돌아갑니다.
`limb_ik.gd`는 팔과 다리에 공통인 두 관절 해석식 보정입니다. 매 프레임 원본 포즈를 평가한 뒤 적용해 보정이 누적되지 않습니다.

`python art/source/characters/build_adventurer.py`로 캐릭터·도끼·망치 GLB를 다시 만듭니다. Python 3 표준 라이브러리만 필요합니다.
Godot에서 가져온 장면을 `scripts/visuals/character_view.gd`로 감싸며 게임 로직은 모델 내부 이름에 의존하지 않습니다.
후속 Blender 모델도 같은 부착점과 외부 API를 유지하면 교체할 수 있습니다.
환경 공통 메시·천막은 `scripts/visuals/expedition_art.gd`, 정적 배치는 `scripts/world/region_world_factory.gd`에 있습니다.
지역 장면 재생성은 `tools/build_world.gd`를 실제 렌더러로 실행합니다. 수동 장면 수정이 있다면 먼저 반영해야 합니다.

## 야영지 2차 적용 · 2026-10-07

`scripts/visuals/camp_art.gd`에서 가까이 보는 원정 소품을 직접 생성합니다.
목공 작업소에는 수리용 판재·톱·망치·예비 바퀴를, 취사장에는 솥·삼각대·화덕·식기·장작을 배치했습니다.
보급 수레에는 장부·지도·짐을 두고 마차의 축·철테·고정 끈·적재물, 짐노새의 가방과 침낭도 같은 재질로 맞췄습니다.
화염은 `assets/shaders/camp_fire.gdshader`의 절차적 셰이더이며 외부 텍스처를 사용하지 않습니다.
바닥의 닳은 흔적은 지형 색으로 섞어 별도 원판의 경계를 없앴습니다.

작은 부품마다 노드를 만들지 않고 재질별 메시로 합쳐 캐시합니다. 움직이는 대열의 새 마차 부품도 MultiMesh를 사용합니다.
정적 출발 야영지와 건설 중인 전진 기지는 같은 소품을 공유합니다. 기지 25%에는 작업소, 50%에는 취사장,
75%에는 화덕이 나타나고, 저장 복원에서는 중복 생성하지 않습니다. 취사나 제작 기능을 추가한 것은 아닙니다.

`collider_specs()`의 상자들을 실제 충돌과 지상 장애물 범위에 함께 사용합니다. 머리 위 차양은 카메라를 막지만 지상 경로는 막지 않습니다.
기지 건물의 자리는 정적 NavMesh 생성 시부터 예약합니다. 가구 배치나 충돌 크기를 바꾸면 지역 장면도 다시 생성해야 합니다.
`tools/capture_camp.gd -- overview|workshop|kitchen|supplies|base|hearth`는 실제 게임 장면의 근접 렌더입니다.
관찰용 카메라에서는 HUD와 떠 있는 이름표만 숨기고, 게임의 배치·조명·모델을 그대로 사용합니다. 저장은 비활성화합니다.

## 공통 규격

- 키 약 1.9m, 발바닥 중앙 원점, +Y 위, 캐릭터 정면 +Z.
- Camera3D의 정면은 -Z이므로 캐릭터와 카메라 축을 혼동하지 않습니다.
- 게임 규칙은 이동과 회전을 결정하고 첫 모델은 제자리 애니메이션을 사용합니다.
- 플레이어와 주민의 공통 스켈레톤을 먼저 정합니다.
- 오른손/왼손 부착점 이름: grip_r, grip_l. 도구별 손잡이 원점을 함께 기록합니다.
- 이동 클립은 제자리 동작이며 실제 이동은 CharacterBody3D가 결정합니다.
- 현재 API: animate(delta, speed, grounded, action, progress, carrying).

## 남은 품질 작업

현재 모델은 직접 작성한 스타일화 캐릭터의 2차 버전입니다. 세 역할의 얼굴·머리, 기본 두 손 접촉과 발 접지를 구현했습니다.
시안 수준의 섬세한 얼굴·옷 주름, 주민별 체형, 망치 작업면 접촉, 손가락 관절·천 물리는 아직 없습니다.
급격한 지형 단차·급회전에서의 발 전환과 공격 자세는 수동 플레이로 더 다듬어야 합니다.
다음 환경 순서는 숲·던전의 전용 환경 자산이며, 야영지 주민의 실제 취사·수리 동작도 남아 있습니다.
표면 디테일과 조명만으로 이 간격을 모두 해결했다고 간주하지 않습니다.

검증: `tools/check.ps1`의 관절 동작·타이밍·장비/짐 복원 검사와 기존 원정 회귀 검사를 함께 실행합니다.
`tools/capture_art.gd -- characters|portraits|poses|strikes|gait|run`은 실제 엔진의 모델·자세 렌더이며, `tools/capture_scene.gd -- camp`는 게임 화면입니다.
