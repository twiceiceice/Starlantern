# 별등 원정기 · Starlantern

성인 체형의 모험가로 던전을 탐험하고, 뒤따르는 비전투 원정대가 자원을 회수하는 싱글 플레이 PC 게임입니다.
Godot 4.7.2 + GDScript로 새로 만든 첫 시제품입니다.

## 지금 실행하기

- **게임만 실행:** `builds/windows/Starlantern.exe`를 엽니다. 같은 폴더의 `Starlantern.pck`가 필요합니다.
- **소스에서 실행:** 프로젝트 폴더의 `Play.cmd`를 엽니다.
- **개발:** `Editor.cmd`를 열고 Godot에서 **F6으로 현재 장면**, **F5로 게임**을 실행합니다.
- 이미 Godot가 있다면 `project.godot`를 가져와도 됩니다. 기준 버전은 4.7.2입니다.

실행 도구는 프로젝트 안의 `.tools`에 Godot를 준비하고, 내보내기 도구는 필요한 템플릿을 추가로 준비합니다.
다른 PC에서는 `Play.cmd` / `Editor.cmd`가 처음에 공식 Godot 실행 파일을 내려받아 SHA-256을 확인합니다.
소스 실행에 Node/npm이나 브라우저, 계정 로그인은 필요하지 않습니다. 설치 후 게임 실행은 오프라인으로 가능합니다.
실행 파일 빌드는 Git에 넣지 않습니다. 소스로 받았다면 아래 내보내기 명령으로 다시 만듭니다.

## 두 지역

- **바람결 초원**: 약 250×306m. 출발 야영지 → 굽은 언덕길 → 솔바람 강의 다리. 바람 풀·깃발, 산 능선, 풀을 뜯는 배경 동물을 배치했습니다.
- **별등 전진 기지**: 약 120×126m. 건설 부지와 군중·마차·확장 부지 → 침엽수 숲과 별잠회랑의 낡은 아치 관문. 숲 안쪽으로 들어가면 차가운 조명과 안개가 서서히 짙어집니다. 기존 기지 건설과 열두 진로 의뢰를 유지합니다.
- 도하 임무와 선발대 도착을 마친 뒤 강 건너 표지판에서 E. 이후 기지 남쪽 보급 표지판 ↔ 출발 야영지 보급 수레로 빠른 이동합니다.
- 전환 중에는 시간·식량 소모가 멈춥니다. 진로 의뢰 진행 중에는 먼저 의뢰를 마쳐야 이동할 수 있습니다.
- 기존 완료 저장은 전진 기지에서 시작합니다. 초기화하지 않고 남쪽 표지판으로 초원에 돌아갈 수 있습니다.

## 첫 대장정 · 별문이 열린 날

사흘 전 북부 계곡의 땅이 갈라지며 지도에 없던 던전 **별잠회랑**이 나타났습니다.
문에서 나온 파수꾼에 첫 측량대가 물러나자, 솔바람 길드는 경비·장인·학자·운반 인력 300명을 모읍니다.
이번 횡단의 목적은 던전 입구를 확보하고 첫 탐사 기록과 표본을 귀환시키는 것입니다.
플레이어의 조사와 동료의 일이 함께 끝나야 길드에 보고할 수 있습니다.

**J 대장정 수첩**에서 일곱 장의 진행, 지금 할 일, 발견한 기록과 약속된 보상을 확인합니다.
수첩을 읽는 동안 게임은 일시 정지됩니다. 처음 메뉴에서 열었다면 닫아도 출발하지 않습니다.

1. **300명의 출발** — 시작 화면에서 **원정에 합류**를 누릅니다.
2. 출발 야영지의 게시판 두 개 중 하나에서 **E**로 맡을 일을 고릅니다. 고르는 순간 원정대 300명과 노새·짐마차가 출발합니다.
   - **토벌**: 행렬을 막는 파수꾼을 직접 정리합니다. 등불은 등불꾼이 느리게 세웁니다.
   - **등불지기**: 길가의 등불 자리(주황 깃발)에 **E**로 등불을 세웁니다. 파수꾼은 경비대가 맡지만 사람을 잃습니다.
3. 구간(바람결 초원, 솔바람 도하장)은 지점 세 개로 나뉘고, 지점마다 역할별 연퀘 단계가 이어집니다
   (예: 수레 자국 조사 → 매복 정리, 옛 등불 기둥 찾기 → 불씨 옮기기). 파란 깃발은 **조사** 지점으로, 걸어가면 완료됩니다.
   내 단계와 원정대의 단계가 모두 끝나면 행렬이 다음 지점까지 실제로 전진하고, 도착하면 다음 단계가 열립니다.
   구간 1을 직접 토벌하면 구간 2에 연속 퀘스트 **파수꾼 우두머리 추적**이 열려 단계가 늘어납니다.
4. 도하를 마치면 다리 건너 표지판에서 **E**로 별도 맵인 **숲의 전진 기지**로 이동합니다. 후미를 기다릴 필요는 없습니다. 기지 터에 도착하면 **자재 나르기**(자재 더미에서 하치장으로 상자 운반) 또는 **습격 막기**를 고릅니다.
   습격자가 남아 있는 동안 건설이 멈춥니다. 기지가 완성되면 이곳이 새 캠프가 됩니다.
5. **별잠회랑의 문턱** — 북쪽 별잠회랑 입구의 파수꾼 셋을 정리합니다. 붉은 원은 약 0.95초 뒤 터지고, 원 밖으로 나가거나 회피의 무적 구간을 이용할 수 있습니다.
6. **첫 탐사의 증거** — 인부들은 등불 빛 안에서만 움직입니다. 토벌 후 던전 입구 안쪽에서 **E**로 전진 등불을 세우면 들어와 표본을 회수하고 기지로 옮깁니다.
   전진 등불은 기름이 줄수록 빛이 좁아집니다. 캠프에서 **E**로 기름을 채울 수 있습니다.
   플레이어는 북쪽 끝의 **기록판**을 등불로 밝히고, 가까이 다가가 땅에 선 상태로 **E**를 눌러 조사합니다.
   등불이 없다면 첫 E로 등불을 세우고 다시 E로 조사합니다. 기록은 수첩에 추가되며, 표본 운반과 조사는 어느 쪽을 먼저 끝내도 됩니다.
7. **별문 앞에 마을을** — 기록 조사와 인부 두 사람의 표본 운반을 모두 마친 뒤 전진 기지에서 **E**로 길드에 보고합니다.
   목재 12·별빛 조각 6·**선발 조사단원** 칭호를 얻고 완료 수첩이 열립니다. 별등 전진 기지는 다음 탐사를 위한 거점으로 남습니다.

수첩의 일곱 장은 출발 → 숲을 잇는 등불 → 문으로 향하는 고개 → 돌아올 곳을 세우다 → 별잠회랑의 문턱 → 첫 탐사의 증거 → 별문 앞에 마을을 순서입니다.

원정대는 사람 300·짐노새 40·짐소 30·짐마차 30을 숫자로 시뮬레이션하고 MultiMesh 군중으로 그립니다. 사람마다 개별 AI는 없습니다.
행렬은 4열 사람 무리와 양옆의 짐노새(짐 자루·말아 묶은 짐), 짐소가 끄는 포장마차가 반복되는 약 190m 대열이라
선두가 기지에 닿을 때 꼬리는 아직 야영지를 빠져나오는 중입니다.
식량은 매초 줄고, 바닥나면 사람이 이탈합니다. 행렬이 멈춰 있는 시간이 곧 비용입니다.

첫 원정을 보고하면 진로 대장정이 열립니다. 공통 원정은 행군 중부터 중간 저장되며, 두 맵의 보급 수레 표지판에서 E로 왕복할 수 있습니다.

## 기지에서 이어지는 주민의 일

기지가 완성되면 **목수 세온**과 **취사 담당 하루**가 작업을 시작합니다. 플레이어가 일일이 재료를 옮길 필요는 없습니다.

1. 세온이 길드 목재를 보급 더미에서 가져와 작업대에서 망치질하고, 회수 상자를 하치장으로 옮깁니다. 상자가 준비되어야 기존 회수반이 안전하고 밝은 현장에서 표본을 회수할 수 있습니다.
2. 회수반이 실제로 귀환하면 세온이 회수품을 가져가 포장하고 보급대에 출하합니다. 출하 한 묶음마다 길드가 식자재 한 묶음을 공급합니다.
3. 하루는 식자재를 취사장으로 가져와 솥을 젓고, 완성된 식사를 배식대에 전달합니다. 완성 시 원정 식량 +60(최대 2400), 배식대 근처에서 **E**로 식사 하나를 먹으면 체력 +35입니다. 체력이 가득 차면 소비하지 않습니다.

최초 식자재 한 묶음과 표본 두 묶음으로 총 세 끼가 만들어집니다. 진로 의뢰를 보고할 때도 회수품 한 묶음이 추가됩니다.
배식대는 기지 북동쪽 취사장 앞이며 식사는 최대 여섯 개까지 비축합니다. 기지 근처 HUD와 주민 이름표에서 진행 상황을 확인합니다.
작업 단계·재고·운반 중 위치를 저장하고, 메뉴·수첩을 열거나 다른 맵으로 이동하면 작업이 멈춥니다. 기지에 적이 접근해도 잠시 대기합니다.
기존 완료 저장은 이미 전달한 표본을 한 번만 인계받습니다. 자유 제작·거래·의료·전리품 경매는 아직 없으며, 첫 보급 순환을 시험하는 단계입니다.

## 네 진로와 자유로운 전투 성장

첫 원정 보고 후 **전진 기지에서 K → 진로 카드 → 의뢰 수락**을 선택합니다. 각 진로에는 세 의뢰가 있고, 한 갈래만 완주해도 최종 칭호를 얻습니다.
첫 의뢰 보고에서 중간 등급, 세 번째 보고에서 최종 등급으로 승급하며 대표 기술이 강화됩니다. 의뢰를 보고한 뒤에는 다른 진로도 선택할 수 있습니다.

| 진로 | 세 의뢰 | R 대표 기술 |
| --- | --- | --- |
| 토벌자 → 정예 토벌자 → 용사 | 파수꾼 토벌 → 추격자 조사·처치 → 두 패턴의 수문장 | 약점 낙인: 전방의 적에게 무기·마법·소환 피해 50% 증가 |
| 호위병 → 원정 기사 → 수호자 | 학자 호위 → 보급품 방어 → 세 차례 매복 속 수레 호송 | 수호 결계: 자신과 호위 대상의 피해 65% 감소 |
| 정찰자 → 길잡이 → 개척자 | 측량 표식 → 맥동 구역 조사 → 추격대 돌파·귀환로 기록 | 바람길: 회피 충전·이동 가속·빠른 조사 |
| 견습 기공사 → 룬기공사 → 룬장인 | 등불 복구 → 동력핵 회수·골렘 조립 → 안정기 복구 | 룬 골렘: 가까운 적을 공격하는 장치 설치 |

의뢰마다 기지에서 E로 보고하면 목재 8·별빛 조각 4와 승급 진행을 받습니다. 호위 대상은 플레이어가 도착한 뒤 적의 공격을 받기 시작합니다.
가까이 동행해야 이동하며 적이 있으면 멈춥니다. 호위 대상 또는 플레이어가 쓰러지면 현재 의뢰만 실패하고, 기지에서 다시 받을 수 있습니다.
조사·복구는 E로 시작하고 잠시 제자리에 서 있어야 합니다. 이동·점프·피격 시 작업이 중단됩니다.
룬장인의 일반 부품은 NPC가 기지 보급 상자로 공급하며, 동력핵만 토벌로 확보합니다.

**K의 전투 기술**은 진로와 무관하게 선택합니다. 좌클릭/1은 **가로베기 또는 별빛 화살**, 2/Q는 **내려찍기·서리 파동·별여우 소환**입니다.
변경해도 슬롯의 남은 재사용 대기 시간은 유지됩니다. 공격 동작과 짐 운반 중에는 변경하지 못합니다.
유효한 공격 한 번당 해당 분야의 숙련을 얻으며, 6·18회에서 숙련 2·3단계로 성장합니다. 빗나감·벽 너머 공격은 숙련을 주지 않습니다.
무기·마법 숙련은 피해를 올리고, 소환 숙련은 별여우의 피해·지속시간을 올립니다. 별여우는 소환 후 첫 적중에만 숙련을 줍니다.
진로 의뢰는 현재 계곡과 던전 입구에서 이어지는 첫 버전입니다. 던전 내부나 새 대륙은 포함하지 않습니다.

## 저장과 재시작

공통 원정의 임무 선택·행군 지점 도착·도하·맵 이동·기지 완성·보고, 기술 조합 변경과 정상 종료 시 저장합니다.
현재 맵, 행군 단계, 이미 처리한 적과 등불, 기지 건설, 인부 작업, 인원·식량·장비·숙련을 이어받습니다.
진로 승급과 보상은 보존하며, 공통 원정 이후 진행 중이던 진로 의뢰는 기지에서 다시 받을 수 있습니다. 버전 1 저장도 호환됩니다.
저장은 Godot `user://expedition.json`(Windows 기본: `%APPDATA%/Godot/app_userdata/별등 원정기 · Starlantern/`)에 기록됩니다.
메뉴의 **새 원정 · 진행 초기화**를 두 번 누르면 새로 시작합니다. 이전 파일은 `expedition.json.previous`로 보관합니다.
거래·자유 건축은 아직 연결하지 않았습니다.

| 조작 | 동작 |
| --- | --- |
| WASD / 방향키 | 카메라 방향을 기준으로 이동 |
| 마우스 이동 / 휠 | 시점 회전 / 확대·축소 |
| Shift | 달리기 |
| Space | 점프 |
| 좌클릭 누르기 / 1 / F | 선택한 기본 공격, 누르고 있으면 반복 |
| 2 / Q | 선택한 보조 기술 |
| R | 선택한 진로의 대표 기술 |
| Ctrl | 이동 방향 회피, 정지 중에는 카메라 전방으로 회피 |
| E | 게시판 퀘스트 고르기, 등불 설치, 자재 운반, 던전 기록판 조사, 길드 보고 / 기름 채우기 |
| J | 대장정 수첩 열기·닫기 (열린 동안 일시 정지) |
| K | 진로·의뢰·기술 조합·숙련 (열린 동안 일시 정지) |
| Esc | 일시 정지, 커서 해제, 계속하기 |
| F11 | 전체 화면 전환 |

회피는 2회 충전이며 2.4초마다 한 번 회복합니다. 시작 후 0.22초 동안 무적입니다.
공격이 적중한 뒤의 마무리 동작은 회피로 취소할 수 있습니다. 공격 준비 동작은 유지합니다.
공통 첫 원정 중 쓰러지면 캠프로 돌아가고 생존한 적은 회복합니다. 진로 의뢰 중 쓰러지면 그 의뢰를 다시 받아야 합니다.

```text
project.godot          프로젝트 설정과 시작 장면

  actors/             플레이어·파수꾼·인부
  camera/             3인칭 카메라와 벽 충돌
  core/               입력·이동 수치·공격 판정

  ui/                 한글 HUD와 일시 정지 메뉴
  visuals/            교체 가능한 임시 캐릭터·타격 효과
  world/              초기 월드 생성 도구
assets/               게임에서 쓰는 폰트·모델·텍스처
art/                  컨셉 참고와 제작 원본 (게임 빌드에서 제외)

```

## 개발 명령

PowerShell에서 이 프로젝트 폴더를 엽니다.

```powershell
# 프로젝트 안에 고정 버전 Godot 준비
.\tools\setup.ps1

# 실행 / 에디터
.\tools\run.ps1
.\tools\run.ps1 -Editor

# 임포트, 자동 검사, 게임 시작 검사
.\tools\check.ps1

# Windows 실행 파일 생성
.\tools\export.ps1
```

Windows 실행 정책이 스크립트 실행을 막는 PC에서는 아래처럼 **해당 프로세스에만** 적용해 실행할 수 있습니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\check.ps1
```

내보내기 템플릿의 최초 다운로드는 약 1.3GB입니다. Windows용 두 파일만 추출해 사용합니다.
설치 도구는 프로젝트 폴더만 사용하며 시스템 PATH나 전역 실행 정책을 바꾸지 않습니다.

## 현재 범위

구현: 3D 이동·달리기·점프·충돌, 마우스 카메라, 회피, 기본 공격·내려찍기, 적의 지면 경고,
퀘스트 게시판과 역할 선택, 원정대 행군(등불·위협에 따른 정지, NPC 조의 대리 처리), 연속 퀘스트 하나,
전진 기지 건설, 동료 둘의 길찾기·대기·작업·운반, 자원 정산, 한글 UI, 일시 정지, Windows 빌드.
신규 던전을 향하는 7장 대장정, J 수첩, 던전 입구의 빛기둥·기록판, 조사와 표본 회수를 묶은 길드 보고.

아직 없음: 시안 수준의 최종 모델·옷 주름, 기존 게임의 4단 콤보·궁극기·습격·특성,
거래·자유 건축, 완성 음악·효과음, 게임패드 설정, 다층 던전과 동적 건축 길찾기.
네 진로·열두 의뢰·대표 기술, 무기·마법·소환의 조합과 숙련, 전진 기지 체크포인트를 구현했습니다.
지하도시 내부와 더 큰 지도, 더 긴 진로 대장정은 후속 작업입니다.
성인 모험 판타지 A 방향의 캐릭터 2차 아트를 적용했습니다. 공통 GLB(19관절·11클립), 세 역할의 얼굴·머리,
곡면 코트와 천·가죽 표면, 전용 어깨 갑옷, 양손 도끼와 짐 접촉, 거리 기반 보행과 경사면 발 접지를 사용합니다.
야영지 2차 아트로 목공 작업소·취사장·보급 수레·장부·짐을 배치하고, 마차 부속·적재물과 짐노새 장비를 다듬었습니다.
전진 기지에도 건설 진행에 맞춰 같은 시설이 나타납니다. 완성 뒤에는 목수·취사 담당의 재료 운반·작업·결과물 전달이 이어집니다.
숲·던전 입구 2차 아트로 침엽수·고사리·쓰러진 가지, 닳은 아치·석벽·돌길·기록판·광물 군락을 적용했습니다.
기지에서 유적으로 이동하면 조명과 안개가 서서히 바뀌며, 바닥 공격 경고는 그늘에서도 보이게 보정했습니다.
봉인된 문 너머의 던전 내부와 AI 시안 수준의 최종 모델 품질은 후속 작업입니다.
캐릭터 원본은 `art/source/characters/build_adventurer.py`이며 Python 3로 다시 생성할 수 있습니다.

기존 웹 프로젝트 `../starlantern` 및 이전 게임은 별도로 보존했습니다.
GitHub 원격 저장소는 [twiceiceice/Starlantern](https://github.com/twiceiceice/Starlantern)입니다.
푸시할 때 GitHub Actions로 검사를 실행합니다. 실행 파일 자동 배포는 아직 연결하지 않았습니다.

## 다른 PC에서 이어서 개발하기

저장소를 내려받습니다. 변경사항을 올릴 때는 쓰기 권한이 있는 GitHub 계정으로 로그인합니다.

```powershell
git clone https://github.com/twiceiceice/Starlantern.git
cd Starlantern
.\Editor.cmd
```

처음에는 공식 Godot 실행 파일을 자동으로 준비하고 편집기를 엽니다.
이미 이 저장소를 받은 PC에서는 변경사항을 보존한 뒤 `git pull --ff-only`로 최신 소스를 받습니다.
게임만 실행하려면 `Play.cmd`, Windows 실행 파일을 만들려면 `tools/export.ps1`을 사용합니다.
