Noto Sans KR font
Source: https://github.com/google/fonts/tree/main/ofl/notosanskr
File: NotoSansKR[wght].ttf, stored locally as assets/fonts/NotoSansKR.ttf
SIL Open Font License 1.1; full text: assets/fonts/OFL.txt (FONT_LICENSE.txt in the Windows build).
Font is bundled for Korean UI and is not downloaded at runtime.

Character direction reference
art/references/character-directions.png is an AI-generated concept comparison
created for this project. Direction C is selected. It is excluded from the game build.

All current geometry, character stand-ins, UI layout and attack effects are
procedurally authored for this project. No external character model, texture pack,
music or game franchise assets are included.
